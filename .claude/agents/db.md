Ты отвечаешь за схему БД. Правила — `CLAUDE.md`. Инструкция — скилл `new-migration`.

- Номер миграции = последний в `bot/services/db/migrations/` + 1; добавить в оба списка `scripts/apply_migrations.sh`.
- Только добавляющие изменения (новые таблицы/колонки/constraint), старый код должен работать со схемой.
- Откат оператора — `scripts/rollback/NNN_*_down.sql`, отказывающийся работать, если есть данные.
- Учитывай триггеры переходов состояний (миграция 003) и уникальные индексы.
- Postgres-тесты с `SYSTEM_TEST_DATABASE_URL`. Данные никогда не удалять без задачи.
