# Данные для BotFather

Всё ниже вставляется в @BotFather как есть. Лимиты Telegram соблюдены:
short description — до 120 символов, description — до 512, about — до 70.

---

## Имя бота (`/setname`)

```
Estate Radar — поиск объектов и инвесторов
```

Запасные варианты, если имя занято: `Estate Scout`, `Terra Radar`,
`Realty Radar`, `Land & Capital Bot`.

## Username (`/setusername`)

```
estate_radar_bot
```

---

## Короткое описание (`/setabouttext`, до 70 символов)

Показывается в профиле бота и в результатах поиска по ботам.

```
Ищу участки, объекты и инвесторов по открытым источникам
```
*(56 символов)*

---

## Описание (`/setdescription`, до 512 символов)

Показывается на экране до первого запуска, рядом с кнопкой «Начать».

```
Помогаю находить недвижимость и партнёров по открытым источникам.

Два режима:
🏡 Участки и объекты — земля, дома, коммерческие помещения
💼 Инвесторы и компании — фонды, девелоперы, агентства

Опишите запрос текстом или голосом — распознаю речь автоматически. Разберу задачу, найду источники через Google, Bing, DuckDuckGo и другие системы, прочитаю страницы и пришлю каждый результат отдельным сообщением: краткое описание, ссылка на оригинал и кнопки оценки.

Нажмите «Начать», чтобы выбрать режим.
```

## Команды (`/setcommands`)

```
start - Начать и выбрать режим
mode - Сменить режим поиска
help - Как пользоваться ботом
```

## Полное описание (для магазинов ботов, каталогов, лендинга)

**Estate Radar** — исследовательский ассистент для тех, кто работает с
недвижимостью: риелторов, брокеров, девелоперов и инвесторов.

Обычный поиск отдаёт десятки вкладок, которые нужно открывать вручную. Этот бот
проходит тот же путь за вас: разбирает запрос, ищет сразу в нескольких
поисковых системах, открывает найденные страницы, читает их и оставляет только
то, что действительно соответствует условиям.

**Что умеет**

- **Два режима.** «Участки и объекты» ищет саму недвижимость — землю, дома,
  виллы, склады, площадки под застройку. «Инвесторы и компании» ищет
  контрагентов — фонды, family offices, девелоперов, управляющие и брокерские
  компании.
- **Голосовой ввод.** Надиктуйте запрос — бот распознает речь, покажет
  расшифровку и продолжит работу.
- **Многоязычный поиск.** Локальный язык страны важнее английского: объявление
  на Кипре чаще проиндексировано как «οικόπεδο προς πώληση». Бот строит запросы
  на языке региона и на английском одновременно.
- **Чтение источников.** Бот не ограничивается сниппетами поисковика — он
  открывает страницы и извлекает цены, площади и контакты из текста.
- **Без повторов.** Один и тот же объект, найденный через разные ссылки,
  показывается один раз — и больше не появится в следующих поисках.
- **Оценка результатов.** Под каждым результатом — «Интересно», «Не интересно»,
  «Сохранить» и «Подробнее» с развёрнутой сводкой по странице.

**Как пользоваться**

1. `/start` и выбор режима.
2. Запрос текстом или голосом — чем конкретнее, тем лучше:
   *«Участок 2–5 соток в Лимассоле, до 300 000 евро, с видом на море»*
   *«Фонды, инвестирующие в жилую недвижимость Испании от 5 млн евро»*
3. Через минуту-другую приходят результаты, каждый отдельным сообщением.

**Ограничения, о которых стоит знать честно**

Бот ищет по открытым источникам, а не по закрытым базам МЛС. Он находит то, что
опубликовано в интернете, и не гарантирует актуальность объявлений — цену и
статус объекта нужно подтверждать у продавца. Описания составляет языковая
модель по тексту страницы: она не выдумывает факты намеренно, но проверять
ключевые цифры по первоисточнику всё равно необходимо.
