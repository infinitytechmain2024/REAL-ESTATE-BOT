# Решения владельца и клиента перед сдачей v2 (O1–O10)

Один документ вместо разрозненных вопросов: что нужно решить, какой вариант предлагается, что это
блокирует. Заполнить галочками и вернуть; код под каждый пункт уже готов и выключен флагом (`docs/v2/HANDOFF.md`).

## O1. Compliance: Apify, группы Facebook, комментарии (`COMPLIANCE.md` §4) — ⛔ блокирует A4, B3-live, D1, D2

Что именно происходит, если включить `ACQUISITION_MODE=apify` и `APIFY_FACEBOOK_COMMENTS_ENABLED=true`:

| Данные | Откуда | Что хранится | Кто видит |
|---|---|---|---|
| Объявления порталов (Idealista, Pisos, Habitaclia, Yaencontre, Milanuncios) | платный актор Apify | url, цена, площадь, район, телефон и агентство **только** при `CARD_EXTRA_FIELDS=true`; у Milanuncios продавец-частник всегда вычищен (`stripSellerPII`) | оператор в карточке |
| Посты открытых групп FB | актор Apify, только публичные группы | текст поста, ссылка, имя автора | оператор |
| Комментарии под постом (инвесторы) | актор Apify по прямой ссылке на пост | текст, имя, ссылка на профиль, классификация «инвестор/нет» | оператор, таблица `investor_leads` |
| Закрытые группы | **нет**: только после вступления человеком, без cookie-акторов | — | — |

Решить (поставить галочку):

- [ ] **1a. Правовое основание** для сбора комментаторов и классификации их намерений (GDPR: законный интерес + оценка баланса, записанная клиентом). Без этого `APIFY_FACEBOOK_COMMENTS_ENABLED` остаётся `false`.
- [ ] **1b. Телефоны частников** с порталов в карточках: `CARD_EXTRA_FIELDS` включать (a) для всех объявлений, (b) только для агентств (`advertiser` есть), (c) не включать. Предлагаем **(b)**: телефон агентства — деловой контакт; для (b) нужна правка в 0.5 ч.
- [ ] **1c. Запросы субъектов данных**: кто отвечает на «удалите меня» (контакт клиента) — у бота есть стирание по ссылке профиля (`COMPLIANCE.md` §6 Erasure).
- [ ] **1d. Риск бана аккаунта FB** — принят ранее; подтвердить, что он относится и к аккаунту, которым вступают в закрытые группы.
- [ ] **1e. Авто-ответы комментаторам** — остаются **выключенными** (инженерный дефолт). Подтвердить.

## O2. Apify: тариф и лимит трат — ⛔ блокирует A3, A4, B5-live, D1

- [ ] Тариф выбран (Free $5/мес хватает на проверку; для D1 нужен Starter).
- [ ] В Apify Console → Billing → **Monthly usage limit** выставлен (предлагаем **$30**).
- [ ] `APIFY_TOKEN` положен в `.env` на VPS (не в чат). Потолок на один запуск уже в коде: `APIFY_*_MAX_USD` + `maxTotalChargeUsd`.

Фактические расходы на живые сэмплы при разработке: Idealista/Pisos/Habitaclia по 5 строк, Yaencontre 5, Milanuncios
3 прогона — суммарно ≈ $0.10; всё подтверждено рабочим (`docs/apify_portals.md`).

## O7. Золотой набор G2–G9 — блокирует D1

Черновик кандидатов (заменить своими формулировками, но типы сохранить — они покрывают все ветки кода):

| # | Тип | Черновик задачи | Зачем |
|---|---|---|---|
| G2 | RE | квартира, Валенсия, покупка, 2–3 спальни, до 250 000 € | провинциальная столица, цена-потолок, `rooms` |
| G3 | RE | дом, Марбелья, покупка, от 200 м², бассейн | город без «capital»-слага (Pisos/Milanuncios), доп. признак в тексте |

| G5 | RE | квартира, Барселона, аренда, до 1500 €/мес | аренда (другие операции у всех порталов) |
| G6 | инвесторы | прямая ссылка на пост FB с ≥ 30 комментариями | B1/B2: чтение комментариев без discovery |
| G7 | инвесторы | «ищу соинвесторов в проекты в Малаге, тикет от 50 000 €» | B3: reach + группы |
| G8 | инвесторы | 2-я ссылка на пост (другой язык/тема) | повторяемость классификатора |
| G9 | both | «участок под застройку в Мадриде ≥ 2000 м² и инвесторы под проект» | C2: режим both, разделение бюджета B4 |

- [ ] Формулировки согласованы, 2–3 ссылки на посты с ≥ 30 комментариями присланы (для G6/G8).
