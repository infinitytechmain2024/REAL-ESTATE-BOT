## Этап 1. Золотой набор G1–G9 (владелец + архитектор, 2–3 дня)

### Как проходит каждая задача
1. Владелец ставит задачу в Telegram ровно текстом из раздела (голосом или текстом), отвечает на вопросы бота так,
   как написано, нажимает «Запустить».
2. Ждёт «✅ Готово» (10–40 мин). Если бот спрашивает «Показать похожие?» — отвечает «Да» (мы хотим видеть всё).
3. Выполняет:
   ```bash
   cd /opt/real-estate-bot
   ./scripts/eval_campaign.sh $(docker compose --env-file .env exec -T postgres sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -Atc "select id from campaigns order by created_at desc limit 1"') | tee /root/eval-last.txt
   ```
4. Присылает архитектору: вывод скрипта, текст отчёта бота, карточки одним zip (как 17.10), и свою ручную разметку:
   для каждой карточки «точная / похожая / мусор» одним словом (например, «5 точн, 3 похож, 1 мусор: №4»).
5. Архитектор вписывает строку в `docs/v2/GOLDEN_SET.md`, на каждый дефект заводит задачу H-серии (одна ветка, один
   PR), после мержа владелец обновляет VPS и при необходимости повторяет задачу.

Общие критерии для всех RE-задач (из DoD мастер-плана): ≥ 70 % отправленных карточек точные по ручной разметке;
0 мусорных хостов (каталоги, статистика, «поиск жилья»); расход ниже `CAMPAIGN_BUDGET_USD` (5 $); все порталы
`completed`; ошибок `kind='error'` ≤ 3 и с понятным кодом; «Вне кампании» = 0.

### Что делать, если задача «не сдана»
| Симптом | Куда смотреть | Обычная причина |
|---|---|---|
| 0 карточек, порталы `completed`, listings 0 | блок 4 eval, `web_listing_source_runs` | запрос к актору не тот (город/категория), см. `docs/apify_portals.md` |
| портал `error` | `error_code`, `apify_runs` | лимит Apify ($8 Free), неверный build, DNS (сеть `egress`) |
| много `invalid_structured_model_response` | блок 7 eval | флаг H9 выключен или запасная модель не задана |
| `http_402` | блок 7 | баланс OpenRouter |
| карточки другого города | `_place_name`, радиус | портал вернул соседний муниципалитет |
| дубли | `same_object`, `_same_facts` | нет телефона/агентства/особенностей в payload |
| «Лимит Facebook» рано | `SAFETY_MAX_FACEBOOK_*_PER_DAY` | две кампании за сутки |
| расход > $2 | блок 7 по моделям; `campaign_costs` с `campaign_id is null` | Sonnet-проверка на сотнях страниц или сторонний сервис |

## Этап 2. Деньги (владелец, 1 час)

1. **OpenRouter**: баланс ≥ $20. Раз в неделю Activity: только модели из `.env`
   (`claude-haiku-5.5`, `claude-sonnet-5.5`, `claude-opus-5.5`). Проверка на VPS:
   ```bash
   docker compose --env-file .env exec -T postgres sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -c "select item, count(*), round(sum(cost_usd),2) usd from campaign_costs where stage=$$llm$$ and kind=$$cost$$ and created_at > now()-interval $$7 days$$ group by 1 order by 3 desc"'
   docker compose --env-file .env exec -T postgres sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -c "select round(coalesce(sum(cost_usd),0),2) off_campaign from campaign_costs where campaign_id is null and created_at > now()-interval $$7 days$$"'
   ```
   Норма: `off_campaign` = 0.00.
2. **Apify**: Free даёт $8/мес — хватает на порталы (≈ $0.06 за кампанию), не хватает на группы FB + комментарии
   (≈ $0.5–2 за кампанию). Решение: Starter с авто-оплатой **или** остаться на Free и принять, что G6–G9 упрутся в
   лимит. Страховки в боте остаются: `APIFY_FACEBOOK_COMMENTS_MAX_USD_PER_POST=1`, `CAMPAIGN_BUDGET_USD=5`,
   `maxTotalChargeUsd` на каждом запуске.
3. **Лимиты в `.env`** после решения по Apify: `SAFETY_MAX_FACEBOOK_GROUPS_PER_DAY=150`,
   `SAFETY_MAX_FACEBOOK_BATCHES_PER_DAY=12` (сейчас 60/6 — две кампании в сутки их выбирают).
4. **Модели**: Haiku разбор, Sonnet проверка, Opus план и отчёт — не менять до конца этапа 1. Перевод проверки на
   Haiku (−$0.5 за кампанию) только после сравнения вердиктов на G1–G2.

   ```cron

   ```
   Проверка через сутки: `tail -5 /var/log/re-backup.log` содержит `OK:`.
2. **Watchdog**: `OWNER_ALERT_CHAT_ID` задан; тест: `docker compose --env-file .env stop analysis-worker`, через
   1–2 мин в Telegram алерт, сервис поднят сам (`ps` → healthy). Если нет — `docs/v2/OPS.md` «Watchdog».
3. **Ротация логов**: `docker inspect -f '{{.HostConfig.LogConfig}}' real-estate-monitor-postgres-1` → `max-size 20m`.
4. **Откат, один раз на пробу**: `CAMPAIGN_AUCTION_DEVIATION=false` → `docker compose --env-file .env up -d
   --force-recreate campaign-runner` → бот жив → вернуть `true`. Это и есть вся процедура отката любого флага.
5. **Секреты**: `APIFY_TOKEN` ротирован 16.10 после утечки в чат (старый отозван в Apify → Settings → Integrations);
   `OPENROUTER_API_KEY` — ротировать, если когда-либо попадал в чат/скриншот; `chmod 600 .env`.
6. **Перезагрузка VPS** — только по процедуре `OPS.md` «Перезагрузка» (бэкап → down → reboot → up → ps).
