# Idealista + Scrape.do Integration — Professional Agent Pack

Этот пакет предназначен для ведения разработки через multi-agent подход.

## Как использовать

1. Загрузи весь этот пакет в Claude Project / Cursor / другой agentic-инструмент.
2. Обязательно добавь также файл `SCRAPING_ANALYSIS.md` (полный анализ текущей архитектуры).
3. Начинай работу от **Orchestrator Agent**.

## Структура пакета

- `AGENTS.md` — описание всех агентов и их зон ответственности
- `SKILLS.md` — реестр всех skills
- `agents/` — детальные карточки каждого агента
- `skills/` — детальные описания skills
- `PLAN.md` — поэтапный план реализации
- `TECHNICAL_SPECIFICATION.md` — техническое задание
- `CHECKLIST.md` — финальный чеклист приёмки
- `PROMPT.md` — стартовый промпт
